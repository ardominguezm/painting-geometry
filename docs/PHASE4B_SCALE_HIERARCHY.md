# Phase IVb — ArtBench scale hierarchy

This phase reuses the 4,000-image ArtBench-10 pilot feature matrix from Phase IV. No image download or feature extraction is repeated.

## Scientific question

At which spatial scales does level-set geometry generalize artistic style to artists that were never seen during training?

The primary protocol is nested artist-disjoint cross-validation. Outer folds are grouped by artist and shared by every experiment. Inner group folds are used only for SVM hyperparameter selection.

## Pre-specified scale contrasts

Geometry-only single scales use 10 descriptors each at reference scales 1, 2, 4, and 8. Fine and coarse pairs are dimensionally matched:

- fine: sigma_ref = {1,2}, 20 curvature features;
- coarse: sigma_ref = {4,8}, 20 curvature features.

The main geometric contrast is `G_fine_s12 - G_coarse_s48`.

For complementary information, the conventional baseline contains 90 features. Each baseline-plus-geometry model is reduced inside the training pipeline to the same 90-feature budget, so scale-specific increments are not attributable to larger input dimensionality.

## Dataset sensitivity

The complete ArtBench-10 pilot and the WikiArt-derived 8-style subset are analyzed separately. The latter excludes Surrealism and Ukiyo-e to reduce the documented source/digitization confound.

## Outputs

- `phase4b_scale_hierarchy_results.csv`
- `phase4b_scale_hierarchy_deltas.csv`
- `phase4b_scale_hierarchy_fold_results.csv`
- `phase4b_scale_hierarchy_per_style.csv`
- one OOF prediction table per dataset
- single-scale and scale-increment figures generated by the Colab notebook

A fine/coarse hierarchy is claimed only when the artist-group bootstrap confidence interval for the pre-specified contrast excludes zero. A scale is described as complementary to the conventional baseline only when its matched-dimension increment has a 95% artist-group bootstrap interval entirely above zero.
